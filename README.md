# Hey Leonard

**The ultimate assistant. Designed voice-first.**

[heyleonard.ai](https://heyleonard.ai)

I spent decades behind a keyboard. Hey Leonard is how I'm leaving it behind: an assistant you talk to, not an app you have to open. It's built by one person, in public, and it's open source. Most of it was built by talking to it.

- **Everywhere you are.** Voice PE speakers running its own firmware, its own phone number, iMessage, and the Claude and ChatGPT voice apps you already use. Same assistant, same memory, whichever you pick.
- **Developers first.** Every project gets its own agent. Talk a bug through from the car: Leonard already has the context, works out which project owns it, and the fix ships before you're home.
- **Provider independent.** Providers are utilities. No lock-in: use the best model today and switch tomorrow.
- **One memory across every model.** What Claude learns, GPT knows. It lives on your own disk.

## Projects

| Project | What it does |
|---|---|
| [voicepe-realtime](https://github.com/TristanBrotherton/voicepe-realtime) | The voice backend for Voice PE speakers: realtime conversation, wake words, speaker recognition and voice memory. |
| [voicepe-realtime-firmware](https://github.com/TristanBrotherton/voicepe-realtime-firmware) | ESPHome firmware that hears "Hey Leonard" on the device itself. |
| [openclaw-voice-call-realtime](https://github.com/TristanBrotherton/openclaw-voice-call-realtime) | Gives Leonard a phone: real calls in and out, with call screening. |

More on the way: Voice Bridge, the Memory Manager and the dev system.
