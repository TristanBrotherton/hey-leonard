# Hey Leonard

**The ultimate assistant. Designed voice-first.**

Hey Leonard is built by one person, in public. It's open source: everything is public or on its way there.

- **Available everywhere.** Voice PE speakers running its own firmware, its own phone number, iMessage, and the native Claude and ChatGPT voice apps.
- **Provider independent.** Providers are utilities. Use the best model today, switch tomorrow, or run it locally.
- **One memory across every model.** It lives on your own disk.
- **Developers first.** Every project gets its own agent. Describe a bug out loud and it's fixed before you're home.

## Projects

| Project | What it does |
|---|---|
| [voicepe-realtime](https://github.com/TristanBrotherton/voicepe-realtime) | The voice backend for Voice PE speakers: realtime conversation, wake words, speaker recognition, voice memory. |
| [voicepe-realtime-firmware](https://github.com/TristanBrotherton/voicepe-realtime-firmware) | ESPHome firmware that hears "Hey Leonard" on the device itself. |
| [openclaw-voice-call-realtime](https://github.com/TristanBrotherton/openclaw-voice-call-realtime) | Gives Leonard a phone: real calls in and out, with call screening. |

More are on their way: Voice Bridge, the Memory Manager and the dev system.
